# Uncertainty-Aware Prediction of Asphalt Pavement Roughness
This repository contains the Python notebook used for the manuscript:

**Uncertainty-Aware Prediction of Asphalt Pavement Roughness Using Bayesian Neural Networks and Gaussian Process Regression**

## Description

This code develops machine learning models for predicting asphalt pavement roughness measured by the International Roughness Index (IRI). The notebook includes deterministic and probabilistic models, including Random Forest, XGBoost, SVR, ANN, Bayesian Neural Network, and Gaussian Process Regression.

## Files

- `IRI_Modeling_Github.ipynb`: Main code notebook.
- `requirements.txt`: Python packages needed to run the notebook.
- `data/README.md`: Description of the required dataset.
